# سامانهٔ هوشمند ساخت رزومهٔ فارسی

یک نمونهٔ اولیهٔ مبتنی بر FastAPI برای استخراج و مدیریت اطلاعات رزومهٔ فارسی، تحلیل شکاف مهارتی، تولید پرسش‌های تکمیلی و ساخت خروجی‌های HTML، PDF و DOCX. برای استخراج اطلاعات با مدل زبانی، از SDK رسمی Google Gen AI و Gemini Developer API استفاده می‌شود.

## پیش‌نیازها

- Python 3.11 یا جدیدتر
- کلید API برای قابلیت‌های مبتنی بر Gemini

## راه‌اندازی در ویندوز

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
```

مقدار `LLM_API_KEY` و در صورت نیاز `LLM_MODEL` را در فایل `.env` تنظیم کنید. فایل `.env` را در مخزن یا بستهٔ تحویل قرار ندهید.

## اجرا

```powershell
uvicorn app.main:app --reload
```

رابط مستندات API در `http://127.0.0.1:8000/docs` و بررسی سلامت سرویس در `http://127.0.0.1:8000/health` در دسترس است.

## قابلیت‌های پیاده‌سازی‌شده

- مدل ساخت‌یافتهٔ رزومه با منشأ و وضعیت اعتبار هر بخش
- پیش‌پردازش متن فارسی با حفظ ایمیل، نشانی وب و شماره تلفن
- استخراج اطلاعات با Gemini و اعتبارسنجی خروجی با Pydantic
- تحلیل شکاف اطلاعات و تولید پرسش‌های تکمیلی
- ذخیره‌سازی موقت JSON و ذخیره‌سازی مبتنی بر پایگاه داده
- API برای گردش گفت‌وگو و مدیریت رزومه
- رندر HTML، PDF و DOCX با پشتیبانی از متن فارسی و راست‌به‌چپ

## کارهای باقی‌مانده

- احراز هویت و محدودسازی نرخ درخواست‌ها
- ارزیابی و انتخاب بهترین نسخه از میان چند رزومهٔ تولیدشده
- تکمیل و ارزیابی یکپارچه‌سازی پایگاه داده برای محیط استقرار
