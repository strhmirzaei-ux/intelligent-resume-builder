# سامانهٔ هوشمند ساخت رزومهٔ فارسی

نمونه‌اولیه‌ای مبتنی بر FastAPI برای ساخت رزومه از راه گفت‌وگو. برنامه متن فارسی را پیش‌پردازش می‌کند، اطلاعات رزومه را با مدل زبانی استخراج و اعتبارسنجی می‌کند، کمبودها را تحلیل می‌کند و پرسش‌های تکمیلی می‌سازد. رابط وب فارسی، مستندات OpenAPI و خروجی‌های JSON، PDF و DOCX دارد.

## پیش‌نیازها

- Python 3.11 یا جدیدتر
- کلید API مدل زبانی برای استخراج و گفت‌وگوی مبتنی بر هوش مصنوعی

## نصب در ویندوز

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
```

## پیکربندی

در فایل `.env`، مقدار `LLM_API_KEY` را با کلید سرویس مدل زبانی تنظیم کنید. پیکربندی نمونه برای Gemini است و `LLM_MODEL` را هم می‌توان متناسب با سرویس تغییر داد. برای یک سرویس سازگار با API اوپن‌ای‌آی، `LLM_BASE_URL` را نیز تنظیم کنید.

به‌طور پیش‌فرض اطلاعات نشست‌ها در فایل‌های JSON و زیر `data/sessions` ذخیره می‌شوند. برای استفاده از پایگاه داده، `DATABASE_URL` را تنظیم کنید. در این حالت، پیش از اجرای برنامه طرح پایگاه داده را با Alembic به‌روز کنید:

```powershell
alembic upgrade head
```

هرگز فایل `.env` یا کلید API را به مخزن یا بستهٔ تحویل اضافه نکنید.

## اجرا

```powershell
uvicorn app.main:app --reload
```

- رابط وب: `http://127.0.0.1:8000/`
- مستندات API: `http://127.0.0.1:8000/docs`
- وضعیت سرویس: `http://127.0.0.1:8000/health`

## مسیرهای اصلی API

- `POST /api/v1/chat/message` — فرستادن پیام و پیشبرد ساخت رزومه
- `POST /api/v1/resumes` — ساخت رزومه از متن
- `GET /api/v1/resumes/{resume_id}` — دریافت رزومه و اطلاعات تحلیل
- `POST /api/v1/resumes/{resume_id}/analyze` — دریافت تحلیل رزومه
- `GET /api/v1/resumes/{resume_id}/json` — دریافت خروجی JSON
- `GET /api/v1/resumes/{resume_id}/pdf` — دریافت خروجی PDF
- `GET /api/v1/resumes/{resume_id}/docx` — دریافت خروجی DOCX

## قابلیت‌ها

- استخراج ساخت‌یافتهٔ اطلاعات رزومه و ثبت شواهد و وضعیت اعتبار داده‌ها
- نرمال‌سازی متن فارسی با حفظ اطلاعات تماس و نشانی‌های وب
- تحلیل کمبود اطلاعات و تولید پرسش‌های تکمیلی
- ذخیره‌سازی JSON یا پایگاه داده، بر اساس `DATABASE_URL`
- تولید PDF و DOCX با پشتیبانی از متن راست‌به‌چپ

قابلیت embedding اختیاری و به‌طور پیش‌فرض غیرفعال است. برای استفاده از آن، وابستگی‌ها را با `python -m pip install -e ".[embedding]"` نصب و `EMBEDDING_ENABLED=true` را در `.env` تنظیم کنید.
